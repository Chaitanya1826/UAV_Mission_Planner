# UAV Mission Planner using Agentic AI

This project is an AI-based UAV Mission Planner built using Groq LLM and LangChain.

## Features
- Takes mission input from user
- Performs battery check
- Evaluates weather conditions
- Checks no-fly zones
- Uses AI for decision making
- Stores mission history

## Technologies Used
- Python
- LangChain
- Groq API

## How to Run

1. Install dependencies:
pip install langchain-groq python-dotenv

2. Create a .env file and add your Groq API key

3. Run the program:
python app.py

## Output
The system provides:
- Mission summary
- Decision (Approved / Rejected / Postponed)
- Reason and recommendation
